# battery475 — result tables (fastest of 3 seeds)

These tables are generated from the receipts by `scripts/make_tables.py`.
The reported number is the fastest seed, with the slow-to-fast range. TTFT
and wall are the fastest. Peak is the highest. The 16K cell is each arm's
fastest ABAB record. The paired 95% interval (Table 3) uses the mean delta.
The captions use ASD-STE100 Simplified Technical English.

1. `01-decode-by-context.md` — decode rate by context (A/C/D/E).
2. `02-arm-ladder-metrics.md` — full metrics per arm and context.
3. `03-abab-16k-paired.md` — 16K ABAB fastest decode and paired deltas.
4. `04-knockouts-16k.md` — supplementary knock-outs on arm C.
5. `05-longcontext-verdict.md` — 255K verdict and W1/W2 probes.
