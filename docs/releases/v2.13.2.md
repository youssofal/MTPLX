# MTPLX 2.13.2

| What you do | 2.13.1 | 2.13.2 |
|---|---|---|
| Ask a coding client to read two files in one streamed turn | 0 of 3 clients ran both reads from that reply | 3 of 3 clients ran both reads from that reply |
| Stream a request for two or three tool calls | 0 of 8 replays delivered every call separately | 8 of 8 delivered every call separately |
| Ask for two tool calls without streaming | 2 of 2 replays delivered both calls | 2 of 2 delivered both calls |

## What changed

**Parallel tool calls now keep their own arguments (#709).** When Inkling 2 Mini wrote each call separately in a streamed answer, MTPLX could give two calls the same index. The client received two argument objects joined together. MTPLX now gives each call its own index on both `/v1/chat/completions` and `/v1/messages`.

## Validated

The three coding clients read two local files using Inkling 2 Mini Optimized Speed. On 2.13.2, each client ran both reads from the first response and answered with the values from both files. On 2.13.1, each first response joined the calls. Two clients recovered by retrying. The third reached the test deadline during retries.

The API replays covered repeated calls to one tool, calls to different tools and three calls in one answer.

## Upgrading

Choose Check for Updates in the MTPLX menu. For a command-line install, run `brew update && brew upgrade mtplx` or `pip install -U mtplx`. The tool-call fix works with your existing model pack.
