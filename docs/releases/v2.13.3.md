# MTPLX 2.13.3

MTPLX 2.13.3 keeps chat streaming smooth above 200 tokens per second on 120 Hz displays, adds a lighter 30 Hz Performance mode, speeds up code rewrites on Inkling 2 Mini, fixes long-prompt GPU timeouts on M1 and M2 Macs (#422), speeds up Flash-Next on M5 Ultra (#682), steps fan speed smoothly with temperature, gives Macs under 48 GB more memory room, and fixes a round of app, cache, embedding, and CLI bugs. Your downloaded packs keep working as they are.

The M5 Max measurements ran on a 128 GB MacBook Pro with fans at maximum, comparing the final 2.13.3 build against the pre-polish 2.13.3 base (`24afa03ad`), which already included the earlier fixes since 2.13.2. In the alternating four-run check, the first pair ran at nominal thermal pressure while the last run ran under heavy macOS throttling. The M5 Ultra measurement (#682) ran separately on a 256 GB M5 Ultra against `main` before merge.

## Smoother chat streaming

- **120 Hz streaming keeps up past 200 tok/s.** In 2.13.2, copy-lane bursts above 110 to 200 tok/s outran the 60 Hz display cadence and made the transcript stutter. 2.13.3 paces reveals on native 120 Hz ProMotion (`60–120 Hz`), raising HTML flush rates from `51.1` to `96.2 Hz` with `0` frame gaps over `50 ms` (`25.0` down to `8.3 ms` p95) and cutting Markdown visual freezes over `50 ms` by `78.6%` (`14` down to `3`).
- **Incremental text layout replaces heavy view rebuilds.** Live prose now renders incrementally in AppKit instead of rebuilding SwiftUI views on every tick, dropping layout updates from `684` to `3` on HTML rewrites and from `156` to `4` on Markdown, while keeping live tok/s updates isolated from the transcript view.
- **Performance mode drops display overhead further.** Turning on Performance mode caps live streaming updates at `30 Hz` (`15–30 Hz`) and uses plain text rendering without Markdown or syntax highlighting while the model decodes.

## Faster code rewrites on Inkling 2 Mini

- **File rewrites keep copy speed instead of stalling.** When a `"rewrite it"` edit changed parts of a file while copying the rest, partial matches at edit boundaries used to trigger 64-token copy lockouts. 2.13.3 judges match quality on a smaller prefix window and steps verify widths smoothly across 8-row tiles while still backing off on real misses, lifting full HTML rewrites from `87.2` to `125.5 tok/s` (`+43.9%`) and follow-up edits from `118.7` to `138.7 tok/s` (`+16.8%`, `0` pauses).
- **Wide copy panels no longer drop off a cliff.** Fixed wide-panel slowdowns across draft-head scoring, memory spills, verify selection, tile alignment, and warm-up pricing.
- **No change to cold coding, vision, memory, or greedy output.** Cold coding latency stayed flat (`29.87` vs `30.36 ms` per step at nominal thermal state), peak memory stayed identical (`19.23–23.24 GB`), vision recognition remained intact, and greedy outputs matched bit-for-bit.

## M1/M2 stability and M5 Ultra speed

- **Long prompts stay under the GPU watchdog on M1 and M2 Macs (#422).** On M1 and M2 chips, long cold prompts on Inkling 2 Mini attend across the entire prefix in one Metal dispatch and could trip the macOS interactivity timeout. MTPLX now splits long full-attention prefills into smaller batches and flushes command buffers between slices on older chips, while M5 Macs keep their single-launch path.
- **Faster Flash-Next decode on M5 Ultra (#682).** Enabled the verified fused verify read on M5 Ultra GPUs. Across 9 requests over 6 alternating boots on a 256 GB M5 Ultra at depth 3, decode sped up `7.5%` to `8.8%` (`21.02` down to `19.54 ms` median verify step) with identical greedy and seeded output and unchanged prompt speed. M3 Ultra stays on the standard path until measured.

## Cooling and smaller Macs

- **Stepped Smart fan curve.** Smart fan mode now steps RPMs smoothly with chip temperature instead of jumping straight to maximum, using tuned profiles for laptops and desktop Macs (Mac Studio, Mac mini, Mac Pro, iMac), a short-turn quiet delay so brief replies stay quiet, RPM verification in the CLI, and fixes so fans always restore cleanly after requests end or cancel.
- **More memory headroom on Macs under 48 GB.** Lowered the memory-guard floor below 48 GB (`512 MiB` minimum on 8 and 16 GB Macs and `0.60 GiB` on 24 GB Macs) while keeping all crash guards active, and stopped counting leased Inkling buffers twice.

## App, Settings, and Dashboard

- **Settings stay put.** Moving the Save bar to a fixed overlay stops the Settings tab from jumping when toggled or refreshed, and Cooling now uses one segmented Fan Mode control (`Default`, `Smart`, `Max`). Loading or restarting Inkling 2 Mini keeps your saved fan and reasoning settings instead of resetting them on background health polls.
- **Full Inkling timing breakdown.** Speed Truth and the Verify Waterfall now split draft time, verify forward time, and overhead cleanly on Inkling 2 Mini without adding extra GPU syncs during generation.
- **Clearer System, Activity, and SessionBank readouts.** The System tab shows the active fan mode and live dual fan RPMs (`7,821 / 7,815 RPM`) even when background thermal polling is off, tool-call-only turns show `"first tool call at ..."` rather than looking like slow text replies, Activity shows the live model, sampler, and resolved reasoning effort, SessionBank reports real held memory (`6.79 GB`) and cache hits without noisy false evictions, and dashboard charts, tiles, and bottom padding line up cleanly.

## Models, Forge, CLI, and reliability

- **Reuse models already on disk.** MTPLX and the app now pick up complete snapshots already downloaded in Hugging Face caches and folders while checking revision and commit freshness.
- **Better Forge search.** Discover now returns up to 500 models with multi-word search across separators and includes Inkling 2 Mini in the fallback catalog.
- **Qwen 3.5 embeddings and reranking (#712).** Supports nested language-model backbones on `/v1/embeddings` and reranking.
- **Keyed `mtplx stop` (#422).** Supports `--api-key`, `--api-key-file`, and `MTPLX_API_KEY`, and reports authentication failures clearly instead of silently exiting.
- **Clean stream errors and prompt cache continuity.** Streaming endpoints log mid-stream errors and record disconnects cleanly, clone-restored Inkling turns preserve boundary logits, `mtplx trace` reads OpenCode 2.3's new SQLite tables alongside older ones, and PyPI package metadata now describes Inkling 2 Mini (#705).

## Experimental, off by default

- **`MTPLX_INKLING_DRAFT_HEAD_BITS` (`4`, `6`, or `8`, off by default).** Builds a quantized copy of dense 16-bit vocabulary heads for Inkling draft scoring only, leaving target weights untouched. Off by default because it uses extra memory.

## Known in this release

- Most measurements ran on a 128 GB M5 Max (and a 256 GB M5 Ultra for #682). Behavior on M1–M4 Macs and smaller memory sizes rests on fallback rehearsals, the 106-launch kernel census, and automated tests; the #422 M1/M2 prefill fix passed parity checks and awaits confirmation on a real M2 Max.
- On Apple Silicon, macOS still reduces GPU clock speeds when a chip gets hot unless Smart or Max fan mode is enabled in Settings.

## Upgrading

The app updates itself (MTPLX menu, Check for Updates). With Homebrew: `brew update && brew upgrade mtplx`. With pip: `pip install -U mtplx`. The packs did not change, so nothing needs to be downloaded again. This release is version 2.13.3, build 2013031.
